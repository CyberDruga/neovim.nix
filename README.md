# My neovim configuration

This config depends on nix to download all the plugins, and most of it's code was pulled from [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim), and from [my previous nvim configuration](https://github.com/CyberDruga/kickstart.nvim).

Usage: 

```shell
nix run .
```

or 

```shell
nix run .#nvim
```

to run the default config.

Or:

```shell
nix run .#small-nvim
```

to run without language specific plugins
